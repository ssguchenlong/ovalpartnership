语言

收录 33 个全球标杆商业街（含 Oval 的成都太古里、北京太古里、深圳大运天地），每个案例配实景图与 11 维设计标注。点击卡片进入 ArchDaily 式详情页：封面大图 + 图廊 + 逐维解析。暂无配图的案例显示优雅占位，在本地 images/<案例id>/ 放入照片后自动显示。

勾选 2–8 个案例进行横向对比。系统按维度列出各案例的标注与星级，并提炼共性成功要素。

输入项目参数并填写城市，系统从 33 个案例库匹配相似标杆与本地类比案例，推送「可量化、可溯源、结合在地」的分维度设计指引：每个维度给出决策逻辑（核心目标 / 决策步骤 / 关键参数 / 出彩要点 / 常见误区）+ 量化依据（带案例实证）+ 适配法则 + 案例实证；并输出项目所在地研判（气候 / 业态 / 人文 / 尺度提示）。可在「关注重点」中直接提问（如「多宽的步行街最适宜本地」）。生成结果将以图文并茂方式呈现。

上传商业街照片 / 效果图，点「发送」即用 Krea gpt-image-2 图生图重绘成一张优化新图（原图与结果可对比、可下载）。输入框可选填重绘要求（如「优化立面比例、增强首层通透率」），不填则用默认优化提示。首次使用请点右上「设置」填入 Krea API Token。

方法论

每个维度的设计法则（92 条）由跨案例归纳而来：描述「在什么条件下，什么做法被验证成功」并附来源案例。指导大师据此把抽象经验转译为针对当前项目的可执行指引，而非泛泛而谈。量化依据引擎（46 条指标）提供明确尺度与数据区间——例如询问「多宽的步行街最适宜合肥」，系统引用 10–12m 主街、4–7m 慢巷、外摆≥2.5m 等区间，并结合在地气候、业态与人文给出建议。

数据来源与边界：案例内容基于公开资料与专业研究（截至 2026 年）整理，用于设计决策辅助与内部研讨；具体项目落地仍需结合现场勘察、规范与专业判断。案例库与法则库均为纯文本，可随时在 data/ 目录扩展。
